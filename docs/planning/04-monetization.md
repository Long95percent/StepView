## P2：商业化实验

- [ ] 坚持免费层包含：本地核心记录、无限回看、完整备份/恢复、可读导出和基本隐私控制。
- [ ] Pro 候选仅在验证需求后实验：端到端加密同步、精美导出、周期报告、高级 AI、更多主题。
- [ ] 不把数据迁出能力、删除账号、恢复备份或安全更新放进付费墙。
- [ ] 先做价格访谈与假门实验，不先搭复杂支付系统。
- [ ] 分别验证一次性买断、年度订阅和 AI 用量自理；避免 AI 成本吞噬毛利。
- [ ] 明确用户自带 API Key 与托管额度两种模式的责任、隐私、成本和失败体验。
- [ ] 家庭版可实验“家庭许可证/自托管支持”，但不承诺尚无支持能力的企业 SLA。
- [ ] 设商业化护栏：付费转化不能以降低免费数据安全或制造焦虑为代价。

### 推荐商业架构：免费核心 + 本地买断 + 云订阅 + AI 按量

推荐不要在早期押注单一订阅。采用四层结构，每层解决不同的价值与成本：

| 层级 | 收费理由 | 收入性质 | 何时推出 | 核心原则 |
| --- | --- | --- | --- | --- |
| Free Local | 建立规模、信任和口碑 | 无直接收入 | 现在 | 核心记录、备份、可读导出永久免费 |
| Pro Local | 高级回顾、外观、导出和效率 | 一次性买断 | 激活稳定后最先推出 | 无持续服务器成本，不承诺终身免费大版本 |
| Plus Sync | 加密同步、版本历史、多设备 | 月/年订阅 | 有明确跨设备需求后 | 经常性收费只对应经常性服务成本 |
| AI Pack | 托管模型、深度复盘、自动整理 | 包月额度/按量 | Agent 安全与评测达标后 | 不售“无限 AI”，不让成本失控 |

推荐套餐边界：

| 能力 | Free Local | Pro Local（买断） | Plus（订阅） | AI Pack（附加） |
| --- | --- | --- | --- | --- |
| 本地目标/节点/日记/回看 | 完整 | 完整 | 完整 | 依附基础版本 |
| 完整备份、恢复、JSON/Markdown 导出 | 完整 | 完整 | 完整 | 不适用 |
| 基础图片分享 | 有 | 有 | 有 | 不适用 |
| 高级主题、精美 PDF/长图、年度册 | 基础 | 完整 | 完整 | 可参与生成 |
| 高级搜索、多个保存视图、批量整理 | 基础 | 完整 | 完整 | 可辅助 |
| 多设备端到端加密同步 | 无 | 无 | 有 | 无 |
| 云端版本历史与设备管理 | 无 | 无 | 有 | 无 |
| BYOK Agent | 可提供有限入口 | 完整工作流 | 完整工作流 | 用户自行承担模型费 |
| StepView 托管 AI 额度 | 无 | 可单买 | 可含少量体验额度 | 主要权益 |
| 核心数据退出权 | 完整 | 完整 | 完整 | 完整 |

- [ ] 套餐命名避免 `Basic/Standard/Premium` 模糊层级，直接使用 `Free Local / Pro Local / Plus Sync / AI Pack` 表达价值。
- [ ] 从 Pro 降级后，用户数据保持可读可导出；仅停止付费能力，不锁住既有内容。
- [ ] Plus 到期先进入本地只读同步宽限期，允许下载完整副本，不立即删除云数据。
- [ ] 每个价格页面同时说明“为什么收费”和“哪些能力永远免费”。

### 盈利版本一：创始用户预售

**适用阶段**：产品 P0 修复后、正式付费功能完成前，用真实付款验证需求。

- 测试方案 A：`¥79–99` 创始 Pro Local，承诺首个 Pro 大版本和明确交付清单。
- 测试方案 B：`¥129–169` 创始支持者，增加未来一个主版本升级或主题/年报包。
- 海外可测试 `$12–19` 与 `$24–29` 两档，必须按当地购买力和税费另行验证。
- [ ] 预售页写清已完成、开发中、不会包含什么、预计交付时间、退款条件和风险。
- [ ] 未交付功能款项可原路退款；不使用虚假倒计时或伪造名额。
- [ ] 先向已经连续使用两周以上的种子用户开放，不用冷流量证明付费。
- [ ] 成功门槛示例：至少 20 个真实付款，且退款/误解比例在可接受范围；具体阈值在实验前锁定。
- [ ] 停止条件：付款主要来自人情支持、用户无法复述购买价值，或交付会挤压 P0 修复。

### 盈利版本二：Pro Local 一次性买断（近期最推荐）

**用户购买的不是“能保存数据”，而是更好的回顾、呈现和长期使用体验。**

- 首发测试价：`¥128 / ¥168 / ¥198` 三个价格点做顺序测试，而非同时造成选择困难。
- 稳定价假设：`¥198–268`；海外可测试 `$29–39`，均为待验证区间而非最终承诺。
- 可选升级策略：当前大版本永久使用；未来大版本优惠升级，安全更新和数据兼容不收费。
- Pro 候选价值：高级路径主题、精美 PDF/长图/年度册、保存视图、批量整理、更多回顾布局、BYOK Agent 工作流。
- [ ] 不人为限制本地目标、节点、日记数量来逼迫付费。
- [ ] 不把备份恢复、原始导出、无障碍、安全更新作为 Pro 卖点。
- [ ] 许可证支持合理数量的个人设备；更换设备有自助解绑，离线有宽限期。
- [ ] 提供 7–14 天完整试用或导出结果带预览水印，购买后立即解除；试用结束不丢数据。
- [ ] 评价指标：试用→付费、退款率、支持成本、首单贡献毛利、90 天活跃，而不只看销售额。
- [ ] 停止条件：付费功能不能提高长期价值，只靠皮肤；或一次性售价不足以覆盖支持与更新成本。

### 盈利版本三：Plus Sync 年度订阅

**仅在用户明确需要跨设备且同步可靠后推出。订阅的理由必须是持续服务，不是把本地功能租给用户。**

- 价格测试：`¥18–28/月`、`¥168–228/年` 起测；成熟后再根据成本与价值测试 `¥25–35/月`、`¥228–298/年`。
- 海外初始假设：`$3.99–5.99/月`、`$35–59/年`，支付渠道、税费和支持成本另算。
- 权益：端到端加密同步、版本历史、设备管理、跨设备快速记录、可选云备份。
- [ ] 同步正式收费前，完成冲突、离线、撤销设备、密钥恢复、误删恢复和跨版本测试。
- [ ] 先做付费候补名单与可退款订金；达到明确需求人数后才建设服务器。
- [ ] 年付作为主选，月付供低承诺试用；不默认勾选自动续费，不隐藏取消入口。
- [ ] 云存储设公平使用上限，按附件等高成本内容分级；纯文本/Board 不用小配额制造焦虑。
- [ ] 到期与降级时提供至少 30 天导出/迁移窗口，并在删除云副本前多次提醒。
- [ ] 上线门槛：同步成功率、恢复成功率、支持工单率和非 AI 毛利达到内部阈值。
- [ ] 停止条件：跨设备需求弱，或同步支持/事故成本高于可接受的订阅贡献毛利。

### 盈利版本四：AI 双轨制（BYOK + 托管额度）

#### 轨道 A：BYOK

- 用户自行提供兼容服务的 Key，模型费用由用户承担。
- Agent 编排、上下文预览、审批、diff、撤销等产品工作流可作为 Pro Local 或 Plus 权益。
- [ ] 明确 Key 会发送到用户选择的服务主机；不承诺第三方服务隐私。
- [ ] 不因 BYOK 无直接模型收入而故意降低安全性或可用性。

#### 轨道 B：StepView 托管 AI

- 测试 `¥19–49/月` 的额度包，按“可完成的复盘/整理次数”表达，不用难懂 token 作为唯一单位。
- 提供一次性加量包，未开启自动续费时绝不自动扣款。
- Plus 可含少量体验额度，但高成本使用单独计费。
- [ ] 不销售无限套餐；为单用户、单任务、每日和月度成本设置硬上限。
- [ ] 在调用前显示预计消耗，调用后显示本月剩余；失败/取消/未产生有效结果的计费规则清楚。
- [ ] 路由到更便宜模型前必须通过任务质量 eval；不能为省成本偷偷降低结果质量。
- [ ] AI 贡献毛利目标初始设为不低于 60%，模型价格波动后自动预警；具体目标随规模校准。
- [ ] 停止条件：AI 付费不能覆盖模型、重试、客服和退款，或错误执行损害核心信任。

### 盈利版本五：导出、主题与年度册内容包

**低风险补充收入，适合已有分享行为后推出，不能成为核心数据出口收费。**

- 单次主题/导出包：测试 `¥9.9–29`。
- 创作者旅程包或年度回顾包：测试 `¥29–59`。
- 全部视觉包年度通行证：测试 `¥49–99/年`，不与核心产品订阅混淆。
- 可选实体年度册：按需印刷，价格覆盖设计、印刷、物流、损耗和售后后再开放。
- [ ] 基础无水印导出和可读数据导出始终免费；付费点是更精美、更多布局和高分辨率。
- [ ] 主题必须保持 WCAG 对比和 reduced-motion，不售不可用的“好看皮肤”。
- [ ] 先观察免费导出实际分享率；没有分享行为时不投入大量模板设计。
- [ ] 用单包购买率、复购、退款和制作维护成本判断，而不是下载次数。

### 盈利版本六：模板市场与创作者分成

**适用阶段**：已有稳定模板使用和用户创作行为后；不是冷启动方案。

- 平台抽成建议从 20% 起测，创作者获得 80%；支付、税费和退款责任写清。
- 可售内容仅为结构、提示与视觉资源，不允许夹带他人私人 Board 数据。
- [ ] 模板上传前自动+人工检查隐私、版权、恶意内容和破坏性脚本。
- [ ] 安装永远先只读预览，再确认创建新空间；禁止覆盖当前 Board。
- [ ] 创作者看到浏览、试用、购买、退款数据，并能下架和更新。
- [ ] 市场上线门槛：至少 1000 名稳定月活或足够高的模板需求，否则供需两端都会空。
- [ ] 停止条件：审核/支付/版权成本超过收入，或模板让产品退化成复杂任务管理器。

### 盈利版本七：家庭许可证与托管服务

#### 自托管家庭许可证

- 测试 `¥299–699` 一次性家庭许可证，覆盖 5–8 个家庭成员、管理 UI 和一定期限更新。
- 可选 `¥99–199/年` 的持续更新/优先支持；停止续费后现有版本和数据继续可用。

#### 托管家庭服务（后置）

- 测试 `¥29–59/月/家庭`，包含加密托管、自动备份和基础支持。
- [ ] 未成年人账号、监护人权限、成员隐私、数据删除和家庭解散必须先完成产品/法律设计。
- [ ] 家庭成员默认数据隔离；付费不能赋予管理员偷看私人日记的能力。
- [ ] 自托管支持边界、受支持环境和响应时间写清，避免无限环境排障吞噬毛利。
- [ ] 停止条件：个人用户没有自然邀请需求，或单家庭支持成本超过首年收入。

### 盈利版本八：训练营/教练/教育授权

**机会驱动，不主动把主产品改造成管理后台。**

- 小型试点可测试 `¥9–19/人/月`，或 `¥399–1499/期` 的小班授权与支持包。
- 价值：学员自有成长路径、选择性提交进展、结业作品集、教练轻量反馈。
- [ ] 私人日记默认不向教练可见；提交的内容由学员逐次或按范围授权。
- [ ] 不做排名、监控时长和强制打卡；聚合数据必须达到匿名阈值。
- [ ] 先由人工支持 3 个付费试点，确认重复需求后才开发机构后台。
- [ ] 评价指标：续期、学员 D30、完成后个人版留存、教练节省时间和隐私投诉。
- [ ] 停止条件：客户核心需求是考勤、绩效和实时监控，与品牌原则冲突。

### 补充收入：赞助、服务与联盟

- [ ] 可开放 GitHub Sponsors/爱发电等自愿支持，权益以感谢和开发日志为主，不承诺核心路线控制权。
- [ ] 为少量自托管用户提供付费安装/迁移服务，按明确范围报价，不把它伪装成可规模化 SaaS 收入。
- [ ] 与课程、书籍、创作者工具合作时只做高度相关且明确标注的推荐，不出售私人行为画像。
- [ ] 不把广告作为默认商业模式；私人日记与成长数据不适合用于广告定向。
- [ ] 赞助、服务和联盟收入单独核算，避免掩盖核心产品没有付费意愿。

### 三套可直接选择的商业版本

#### 商业版本 A：纯本地买断（最稳妥）

- 组成：Free Local + Pro Local + 视觉/导出包。
- 优点：与本地优先定位一致、工程和运维成本低、能最快获得第一笔真实收入。
- 缺点：收入波动、升级和长期支持需要新版本策略。
- 适合：未来 0–6 个月，产品仍在证明留存阶段。
- [ ] 默认选择此版本开始，不以“必须有订阅”推迟收费验证。

#### 商业版本 B：本地买断 + 同步订阅（长期推荐）

- 组成：A + Plus Sync；本地用户和云用户都能完整使用并随时退出。
- 优点：买断建立信任，订阅覆盖持续服务器成本，经常性收入更健康。
- 缺点：同步、密钥、冲突、客服和合规复杂度显著上升。
- 适合：D30 留存和跨设备付费候补都成立后。

#### 商业版本 C：免费核心 + AI 收入优先（不建议当前采用）

- 组成：Free Local + BYOK Pro 工作流 + 托管 AI Pack。
- 优点：AI 付费意愿可能更直接，传播话题强。
- 缺点：成本不可控、同质化、信任风险高，并会掩盖核心记录循环不成立。
- 适合：Agent eval、安全审批和重复使用需求已被证明后，作为附加线而非母商业模式。

#### 商业版本 D：家庭/教育垂直（机会型）

- 组成：家庭许可证或训练营授权 + 支持服务。
- 优点：客单价更高，真实场景可能提供明确预算。
- 缺点：销售、权限、合规和客服会把产品带向完全不同的公司。
- 适合：已有主动上门且愿意预付的客户，不作为大众版默认路线。

### 定价验证方法

- [ ] 先访谈使用两周以上的活跃用户，询问失去 StepView 的替代方案和损失，而不是直接问“你愿付多少钱”。
- [ ] 使用 Van Westendorp 四问了解“太便宜/划算/贵但可接受/太贵”区间，仅作参考。
- [ ] 对同一价值做顺序价格测试，避免同页三档锚定干扰结果。
- [ ] 假门实验点击后明确写“正在开发”，可选择候补或可退款订金，不伪装已经可买。
- [ ] 把真实付款、退款、持续使用和客服成本作为证据；问卷里的“愿意付”权重较低。
- [ ] 记录价格拒绝原因：没价值、时机不对、支付方式、信任不足、负担不起，分别处理。
- [ ] 不轻易永久降价；可用创始价、学生价或地区价测试，但规则透明且防止套利不过度侵入隐私。
- [ ] 所有实验预先写样本、时长、主指标、保护指标和停止条件，不看到结果后再改成功标准。

### 单位经济与财务看板

每个 SKU 独立核算，不能用本地买断收入掩盖云同步或 AI 的亏损。

- `净收入 = 含税售价 - 税费 - 支付/商店渠道费 - 退款`
- `贡献毛利 = 净收入 - 模型 - 存储 - 流量 - 邮件/登录 - 第三方服务 - 可归因支持成本`
- `贡献毛利率 = 贡献毛利 ÷ 净收入`
- `CAC = 渠道内容、投放和可归因人力 ÷ 新增付费用户`
- `回本月数 = CAC ÷ 每付费用户月贡献毛利`
- `LTV` 只在有足够留存历史后计算，不用乐观的永久订阅假设。

- [ ] Pro Local 目标：首单贡献毛利覆盖支付、退款和预期支持/更新准备金；按季度复核。
- [ ] 非 AI 订阅初始目标毛利率不低于 80%–85%，否则先修成本和定价。
- [ ] AI Pack 初始目标毛利率不低于 60%，并对模型涨价、重试和高用量做压力测试。
- [ ] 家庭/教育服务把创始人支持工时按市场成本计入，避免“免费加班所以盈利”的假象。
- [ ] 每月看 MRR/一次性收入、付费转化、续费、退款、流失、ARPPU、贡献毛利、CAC 回本和支持小时。
- [ ] 为模型、同步、支付和客服设单用户成本告警；极端用户先沟通公平使用，不能突然锁数据。

### 支付、许可证、退款与降级体验

- [ ] 中国用户优先支持熟悉的支付方式，海外支持主流信用卡/PayPal；税务和发票责任上线前确认。
- [ ] 支付回调幂等，重复通知不重复发货；失败、退款、拒付和取消订阅有测试。
