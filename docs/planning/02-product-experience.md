## P0：首次激活与核心可用性

### 做一个完全非破坏的新手引导

- [ ] **[P0]** 替换 `src/main.jsx:1415-1429` 的 `Tutorial / Coming soon`。
- [ ] 首次流程控制在 60 秒：选择一个真实目标 → 记录已经做过的第一步 → 看见路径变化 → 了解数据存在哪里。
- [ ] 示例只在只读动画/独立沙盒中演示；“试用模板”必须先预览，再由用户确认导入为**新空间**。
- [ ] 允许随时跳过、稍后继续、重新打开；跳过后不反复打扰。
- [ ] 引导步骤用真实可操作控件，不做“下一步×8”的遮罩幻灯片。
- [ ] 完成引导后给出下一个最小动作“明天回来补一步”，不强迫开启 Agent 或创建复杂结构。
- [ ] 验收：5 名目标用户中至少 4 名无需口头帮助，在 3 分钟内创建真实目标和第一步；0 次误写样例。

### 让第一步足够快

- [ ] 新增全局“记录一步”入口，支持快捷键、菜单栏/托盘入口或桌面快捷动作。
- [ ] 快速记录只要求“发生了什么”，目标可最近使用/搜索选择，其余信息稍后补充。
- [ ] 从启动到保存一条足迹的中位时间目标小于 10 秒。
- [ ] 空 Board 首屏只保留一个主行动和一段价值说明，降低同时出现的功能数量。
- [ ] 根据用户选择“学习 / 项目 / 生活”调整文案建议，但不自动创建内容。
- [ ] 用户第一次保存后立即显示它在路径中的位置，并明确“已保存到哪里”。

### 统一发现性，不靠猜手势

- [ ] 文档与实现统一：当前文档写单击展开，而 `src/main.jsx:1177-1181` 实际为双击；选择一种主要行为并全局一致。
- [ ] 为新增、编辑、完成、分支、连接、删除提供可见按钮或选中后的操作条；右键只作为加速方式。
- [ ] 双击、hover、12px 连线点和 Delete 键均提供触屏及键盘等价入口。
- [ ] 首次使用隐藏交互时给一次性轻提示；帮助页提供可搜索的快捷键清单。
- [ ] 所有可操作目标至少 44×44 CSS px；精细连线点可扩大不可见命中区。
- [ ] 节点和目标支持编辑名称、描述、日期、状态、图标与所属路径，不再要求删掉重建。
- [ ] 未保存表单点击遮罩时不得直接丢草稿；提示保存/放弃/继续编辑。

### 错误不能伪装成空状态

- [ ] 为 Board、日记、Wins、Agent 分离 `loading / empty / error / ready / stale` 状态。
- [ ] 读取失败时不得显示“还没有内容”；展示错误来源、是否仍有本地缓存、重试和恢复入口。
- [ ] 统一 toast 队列，避免新 toast 清除旧 timer；关键错误保持到用户处理，不在 1.7 秒后消失。
- [ ] 错误文案使用用户语言，例如“AI 服务暂时不可用”，不要直接暴露 Redis、Mem0、SQLite 堆栈。
- [ ] 提供“复制诊断信息”，默认脱敏正文、密钥、用户名、路径和 IP。

## P1：信息架构与核心产品体验

### 重构侧栏和导航

- [ ] 将当前过载侧栏整理为：`路径`、`日记`、`回顾` 三个一级区；Agent、设置、数据管理进入清晰的次级入口。
- [ ] `Clear` 不长期暴露在一级侧栏；移动到数据管理的危险区。
- [ ] Folder、Export 等开发者化命名改为用户语言：`数据位置`、`备份与导出`。
- [ ] 当前页面、账号、保存状态、离线状态有明确但不抢眼的层级。
- [ ] 支持折叠侧栏、窄窗底部导航和记忆上次位置。

### 让画布能承载长期数据

- [ ] 增加明确缩放按钮、当前比例、`适应全部`、`回到当前位置`、重置视图。
- [ ] 增加目标/节点搜索与定位；搜索结果在画布中高亮并可逐个跳转。
- [ ] 大 Board 增加小地图或目标总览，不要求用户无限拖动找内容。
- [ ] 新目标放置使用真实包围盒避碰；当前约 80px 偏移小于约 280px 卡片跨度，容易重叠。
- [ ] 新节点和支线使用可预测布局或局部自动排版，避免随机锚点持续制造交叉线。
- [ ] 提供“整理当前目标”“整理选中区域”，先预览布局变化，用户确认后应用，并可撤销。
- [ ] 支持多选、对齐、分组移动和框选；先验证重度用户确有需要再扩大功能。
- [ ] 区分“计划”“已发生”“关键时刻”“休息/绕路”，但不让状态系统变成复杂项目管理器。
- [ ] 目标过多时提供轻量归档、标签与筛选，不默认把所有历史目标同时渲染。
- [ ] 拖拽时仅更新视觉状态，pointerup 后合并持久化；避免每次 pointermove 保存整份 JSON。

### 做好节点详情与编辑

- [ ] 单击节点打开轻量详情；再次明确操作才进入完整编辑，避免误触。
- [ ] 支持正文、发生时间、心情/类型、标签、相关日记、附件链接等渐进字段，默认只露出最少字段。
- [ ] 自动保存草稿并显示状态；Esc 关闭前判断未保存内容。
- [ ] 节点可移动到另一目标或支线，先展示连线和引用变化。
- [ ] 支持复制节点但默认不复制私人日记和附件，复制范围由用户确认。
- [ ] 冲突或循环连接给出具体解释和修复建议。

### 完成画廊与成就真正服务“回看”

- [ ] Wins 卡片提供清晰文字操作：查看旅程、恢复、导出、删除；图标按钮需 tooltip、可访问名称和确认。
- [ ] 完成目标后生成可编辑的回顾：起点、关键步骤、困难、转折、结果和下一步。
- [ ] 恢复完成目标时说明会回到哪个位置，保留完成日期和历史快照。
- [ ] 成就从“收集徽章”转向对真实行为的温柔反馈，避免大量廉价、重复奖励。
- [ ] 允许关闭庆祝、降低动画强度、隐藏成就系统。
- [ ] 建立年度/月度“我走过的路”，优先使用本地数据生成，默认不上传。

## P1：日记、回顾与长期留存

- [ ] 修复日记固定 `limit: 200` 导致第 201 条后无声消失：使用游标分页、总数提示和虚拟列表。
- [ ] Timeline 与 Day 两种视图共享一致的搜索、标签、类型、目标和日期筛选语义。
- [ ] 明确时区存储策略；相对日期、跨午夜、夏令时、修改系统时区均有测试。
- [ ] 日记支持编辑历史、自动草稿、删除恢复和导出；关键更改可看到时间。
- [ ] 从节点写日记时自动建立可见的双向关联，但用户可解除关联。
- [ ] 提供每周一次的温柔回顾：本周走过什么、哪里卡住、下周最小一步；允许完全关闭。
- [ ] 回顾生成前先展示数据范围；AI 总结必须单独确认发送内容，支持纯本地模板总结。
- [ ] 增加“没有进展也可以记录”的入口：休息、放弃、改变方向都能成为有效记录。
- [ ] 搜索匹配标题、正文、目标和标签，并高亮命中；大数据量下保持流畅。
- [ ] 导出 Markdown/PDF 时保持时间线、目标关系和隐私选择，结果可在导出前预览。

## P1：Agent 从工程能力变成可信产品

### 首次配置与日常入口

- [ ] 将首次使用拆为：选择服务商/本地模型 → 选择模型 → 连接测试 → 权限说明 → 开始。
- [ ] 模型列表与能力由配置/探测获得，不在多处硬编码 `gpt-5.1`；发布前用官方文档与真实兼容测试核对。
- [ ] 支持“暂不使用 AI”，核心记录、回顾、导出完全可用。
- [ ] 显示本轮会发送哪些上下文、发往哪个主机、预计用量；默认最小上下文。
- [ ] 对普通用户隐藏 Redis、Mem0、embedding 等实现细节，放入高级诊断。

### 安全执行与可理解审批

- [ ] 审批卡片以用户语言展示“会新增/修改/删除什么”，可展开技术详情。
- [ ] 所有写操作先生成稳定 diff；批量操作支持逐项取消、整体批准和整体撤销。
- [ ] 明确区分只读建议、草稿和实际执行；Agent 不得用模糊文案诱导授权。
- [ ] 审批过期、Board 已变化、部分失败时重新计算，不执行旧计划。
- [ ] 为高风险工具设置最小权限、调用次数、数据量、时间和费用上限。
- [ ] 提供 Agent 活动记录：何时读取什么类型的数据、建议什么、用户是否批准、结果如何。
- [ ] 私人日记默认不进入上下文；按本次、目标或永久授权，永久授权可随时撤销。

### 可靠性、成本与评测

- [ ] 非流式 `completeChatWithTools` 增加与流式请求一致的 timeout、AbortSignal、重试上限和取消按钮。
- [ ] 断流或取消后不留下半写入状态；重试不重复执行工具。
- [ ] 建立离线 eval 集：创建目标、补一步、跨目标连接、日记总结、拒绝越权、恶意 prompt、空上下文。
- [ ] 对每个 Agent 版本记录任务成功率、错误执行率、审批接受率、撤销率、延迟和成本。
- [ ] 上线门槛：写操作 0 越权、0 未审批执行，关键任务成功率达到预设阈值后再扩大入口。
- [ ] 对 OpenAI-compatible 服务做契约测试，而不是假设所有服务都支持相同 tools/streaming/usage 格式。
- [ ] Embedding 或记忆服务不可用时优雅降级，不阻断普通对话与核心 Board 操作。
- [ ] 给用户提供会话/记忆查看、编辑、删除、全部清除与导出能力。

## P1：视觉、品牌、响应式与无障碍

### 视觉方向

- [ ] 从“高密度赛博玻璃 + 发光”收敛为“轻、暖、诚实的私人地图”：减少无语义玻璃层、霓虹描边和持续动画。
- [ ] 先重建信息层级、留白、字号、对比和点击状态，再做插画或装饰。
- [ ] 建立 design tokens：颜色、文字层级、间距、圆角、阴影、边框、运动时长和 z-index。
- [ ] 正文字号原则上不低于 14px；清理大量 9–12px 关键文本。
- [ ] 统一中文默认界面，清理登录、侧栏、节点、画廊和成就中的中英混排；品牌语可保留英文副标题。
- [ ] 建立真实品牌资产：应用图标、favicon、空态插图、分享卡模板、截图规范。
- [ ] 提供浅色/深色/跟随系统和高对比主题；先保证可读性，再追求氛围。

### 响应式与触屏

- [ ] 移除 Shell 固定 `300px 1fr` 的单一布局；为窄窗、平板、手机定义断点和导航模式。
- [ ] 家庭 Web 在 360px 宽度可完成登录、记录一步、查看日记和备份状态。
- [ ] 触屏支持平移、缩放、长按菜单的可见替代；避免拖动画布与拖节点手势冲突。
- [ ] 手机端不强求完整自由画布编辑，优先做好快速记录、列表回顾和只读路径浏览。
- [ ] 测试软键盘、刘海/安全区、横竖屏、200% 缩放和小高度窗口。

### 键盘、读屏和运动

- [ ] 用共享 Dialog 组件统一模态：焦点圈定、Esc、背景 inert、标题关联、关闭后恢复焦点。
- [ ] 节点不再只是不可聚焦的 `<article>`；提供语义、Tab 焦点、Enter/Space 激活、方向键导航和可见 focus ring。
- [ ] SVG 连线、删除和恢复等指针操作提供键盘等价路径；不要在 `aria-hidden` 容器中放可交互按钮。
- [ ] 图标按钮都有可访问名称；颜色不是唯一状态提示。
- [ ] 对文本和交互控件做 WCAG 2.2 AA 对比检查。
- [ ] 支持 `prefers-reduced-motion`，并提供庆祝强度开关；关闭后停用 Emoji rain、视差和大幅缩放动画。
- [ ] 自动化加入 axe 检查，人工覆盖 NVDA/VoiceOver、仅键盘和 200% 缩放。

## P2：家庭 Web 和多端策略

- [ ] 将“个人本地桌面版”作为大众主叙事；家庭版先定位为高级自托管场景，不与 C 端首页并列争抢认知。
- [ ] 网关返回 capabilities：是否允许注册、是否支持 Agent/备份/邀请；前端据此显示入口，避免注册永远可见却必然失败。
- [ ] 家庭版增加管理员界面：邀请/禁用账号、重置密码、查看存储健康、触发备份、查看版本。
- [ ] 账号创建改为一次性邀请或管理员批准，而不是要求普通家庭用户执行容器命令。
- [ ] 明确家庭成员之间默认完全隔离；若未来共享目标，逐目标授权且有审计记录。
- [ ] 提供 HTTPS/反向代理指南、可信代理配置、局域网暴露警告和安全检查页。
- [ ] 为升级做数据库兼容、备份、回滚和停机说明；容器健康检查不等于数据可恢复。
- [ ] 在决定云同步前，先验证用户是否愿意跨设备以及愿意为端到端加密同步付费。
- [ ] 若做同步，先定义冲突模型、离线队列、设备撤销、密钥恢复和端到端加密威胁模型。
