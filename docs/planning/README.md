# StepView 规划中心

> 审查日期：2026-10-16  
> 结构整理：2026-10-19  
> 当前版本：`1.1.0`

StepView 的主方向是：**把长期目标，走成一条看得见的路。** 当前优先级依次为：数据可信 → 首次激活 → 长期留存 → 自然传播 → 商业化。

## 推荐阅读顺序

1. 日常推进先看 [执行计划](09-execution-plan.md)，每周只领取 3–5 项。
2. 做产品决策时看 [产品定位](01-product-positioning.md) 和 [产品体验](02-product-experience.md)。
3. 准备获客和收费时看 [传播增长](03-growth-and-distribution.md) 与 [商业化](04-monetization.md)。
4. 开始实现和发布前看 [安全隐私](06-security-data-privacy.md)、[工程待办](05-engineering.md)、[质量发布](07-quality-and-release.md) 和 [部署运维](10-deployment-and-operations.md)。
5. 所有假设必须回到 [研究与指标](08-research-and-metrics.md) 验证。

## 当前阶段

- 先关闭会造成数据丢失、账号越权、错误数据空间或无法恢复的 P0。
- 再完成 60 秒首次激活、10 秒记录一步和可信保存状态。
- 留存成立后再放大分享、传播和 Pro Local 收费验证。
- 同步、家庭、机构版和 AI 托管都必须满足各自启用条件，不提前重投入。

## 永久红线

任何 Demo、模板、教程、导览或测试数据都不得自动写入、覆盖或替换用户 Board。示例只能位于只读弹窗、独立沙盒，或在预览影响后由用户明确确认导入；默认创建新空间并保留恢复点。完整规则见 [战略原则与全局约束](00-strategy-and-rules.md#不可破坏的产品红线)。

## 维护规则

- 每个主题只在一个文件维护；跨主题内容用链接，不复制第二份任务。
- [执行计划](09-execution-plan.md) 负责顺序和状态，领域文件负责原因、方案与验收标准。
- 新任务优先使用稳定 ID，并记录负责人、目标版本、依赖和完成证据。
- 已完成事项定期归档，主规划只保留仍需决策或执行的内容。
- `产品说明书.md` 描述已发布能力；本目录描述未来假设和待办，不能混为产品承诺。
