## 指标定义

- [ ] 定义激活事件：用户首次会话内创建 1 个**真实目标**、记录第 1 个真实步骤，并在 7 天内回来记录第 2 步。
- [ ] 北极星指标使用“每周至少新增 2 个真实足迹的活跃用户数（W2S）”，不只看下载量或 DAU。
- [ ] 同时记录：安装→打开、打开→建目标、建目标→记第一步、D1/D7/D30 回访、目标完成、周回顾打开、导出/分享成功率。
- [ ] 设保护指标：崩溃率、保存失败率、恢复成功率、误删恢复率、Agent 撤销率、卸载/退出原因、遥测拒绝率。
- [ ] 区分“功能使用”与“价值达成”：打开 Agent 不算成功，完成一次被采纳且可撤销的建议才算。
- [ ] 事件字典写清事件名、触发时机、字段、隐私级别、保留期限和负责人。
- [ ] 默认仅保留不含正文的必要本地诊断；产品分析遥测采用明确 opt-in，并提供随时关闭与删除入口。
- [ ] 建立每周产品复盘：只回答激活、留存、失败和用户原话，不用虚荣指标掩盖问题。

## 用户研究与实验清单

- [ ] 访谈 5 名刚开始长期目标的人：现在如何记录、为何中断、何时想回看。
- [ ] 访谈 5 名使用 Notion/待办/手账但放弃的人：压力来自哪里，什么反馈会让他们回来。
- [ ] 观察 5 名新用户无指导完成首次记录，记录每次停顿、误点和提问。
- [ ] 对流失用户只问一个问题：“你本来想用它完成什么，哪里让你停下了？”
- [ ] 实验 A：空白创建 vs 三类问题引导；比较真实目标创建率，不导入模板数据。
- [ ] 实验 B：完成后即时庆祝 vs 周回顾；比较 D7 留存和动画关闭率。
- [ ] 实验 C：画布首屏 vs 快速记录首屏；比较 10 秒内首条记录率。
- [ ] 实验 D：旅程图片 vs Markdown 回顾；比较导出与主动分享率。
- [ ] 实验 E：Agent 常驻入口 vs 使用到第 3 次后提示；比较激活率、困惑率和 Agent 成功率。
- [ ] 每个实验预先写假设、主指标、保护指标、样本/时间和停止条件；失败结果也记录。
- [ ] 建立“需求证据等级”：用户原话 < 重复行为 < 付费意愿 < 实际付费；据此排优先级。
