## 30 / 60 / 90 天执行路线

### 0–30 天：先让人敢用、会用

- [ ] 清除真实输入框样例值，并补非破坏教程测试。
- [ ] 修复网关失败静默切换与家庭模式免密切换账号。
- [ ] 上线保存状态、统一错误态、删除撤销/恢复点。
- [ ] 上线数据管理 UI：备份、校验、恢复、数据位置。
- [ ] 完成 60 秒真实目标引导和 10 秒“记录一步”。
- [ ] 修复目标/节点编辑、文档与单/双击不一致、注册 capability。
- [ ] 选择首个 ICP，完成至少 10 次访谈和 5 次无指导可用性测试。
- [ ] 建 CI 和最关键桌面 E2E；在正常环境复跑全部测试与 audit。
- [ ] **阶段门槛**：0 已知数据丢失路径；80% 测试用户 3 分钟内激活；保存/恢复状态可解释。

### 31–60 天：证明用户愿意回来

- [ ] 上线周回顾、日记分页、搜索定位、Fit all 和窄窗核心流程。
- [ ] 完成视觉 tokens、中文一致性、共享 Dialog、键盘与 reduced-motion 基线。
- [ ] 拆分前端主包，优化拖拽保存与大 Board；建立性能预算。
- [ ] 将 Agent 改为清晰配置、上下文预览、稳定 diff、原子撤销和 eval 门禁。
- [ ] 招募 20–50 名种子用户连续使用 4 周，每周访谈与修复最高频障碍。
- [ ] 上线母定位、学习场景和创作者场景三版页面，并对两周活跃用户做价格访谈/Pro 假门。
- [ ] 若 P0 已清零且付费价值清楚，小范围测试可退款创始 Pro Local 预售。
- [ ] **阶段门槛**：D7、W2S 和周回顾复用率出现稳定提升；关键保存失败可恢复；无跨账号泄漏。

### 61–90 天：只放大已经成立的价值

- [ ] 上线隐私优先的旅程图片/PDF/Markdown 导出和 5 个只读模板。
- [ ] 重做普通用户 README/落地页、截图、30 秒演示和签名安装包。
- [ ] 选择 1–2 个渠道做 8 周内容/发布实验，追踪激活和 D7，不只追下载。
- [ ] 若预售证据成立，交付 Pro Local 最小包并验证自然用户付费；不先做复杂同步或团队协作。
- [ ] 完成自动更新、发布回滚、诊断包、安全与贡献文档。
- [ ] **阶段门槛**：自然新增用户能达到同等或更高激活；分享不泄露私人信息；留存先于投放扩大。

## 当前明确暂缓（避免做散）

- [ ] 在 D7/W2S 未证明前，暂缓公开社交 Feed、点赞、关注和排行榜。
- [ ] 在单人数据模型、撤销和冲突解决稳定前，暂缓实时多人共同编辑。
- [ ] 在用户明确需要跨设备前，暂缓自建复杂云同步。
- [ ] 在核心首屏足够清楚前，暂缓增加更多节点类型、支线类型和成就数量。
- [ ] 在 Agent eval、审批和撤销达标前，暂缓让 Agent 自动执行高风险写操作。
- [ ] 在品牌与安装体验达标前，暂缓大规模投放和付费买量。
- [ ] 暂缓企业权限、组织架构、工单式项目管理等会稀释“个人成长路径”的需求。
- [ ] 暂缓用技术名词作为卖点；用户购买的是“看见自己走过的路”，不是 SQLite、Redis 或 RAG。
