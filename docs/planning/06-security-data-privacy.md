- [ ] 新增回归测试：首次启动、打开教程、跳过教程、切换语言都不会新增或修改 Board 数据。

### 禁止连接失败静默切换数据空间

- [ ] 显示明确的“连接失败”页面，包含当前模式、目标地址、最后成功时间、重试、诊断和返回按钮。
- [ ] 仅在用户明确选择后进入只读离线模式；不得创建看似相同但实际分叉的新账号空间。
- [ ] 重新连接时检测本地与服务端是否分叉，展示差异并要求用户选择合并/保留副本，禁止最后写入者静默覆盖。
- [ ] 增加网关离线、超时、401、5xx、损坏响应和重连的端到端测试。

### 修复家庭桌面模式免密切换账号

- [ ] 普通用户不得枚举其他账号的敏感信息；账号列表只显示允许公开的名称/头像。

### 所有破坏性操作可撤销

- [ ] **[P0]** 覆盖 `src/main.jsx:1241`、`1247-1258`、`1266-1273`、`1693` 等永久删除路径，统一进入回收站或命令式 Undo。
- [ ] 删除目标前显示影响摘要：节点、支线、跨目标连线、日记引用、贴纸、成就和完成记录数量。
- [ ] 清空 Board 不再只使用原生 `confirm`；要求二次确认、输入名称或等待倒计时，并先生成恢复点。
- [ ] 节点、贴纸、连线、目标、完成旅程删除后提供不少于 10 秒的撤销入口，关闭应用后仍可在回收站恢复。
- [ ] 回收站展示删除时间、来源目标、关联数据，并支持单项恢复/永久删除/清空。
- [ ] 永久删除前再次确认；删除结果写审计记录，但不记录正文敏感信息。
- [ ] Agent 造成的批量变更必须作为一个原子操作整体撤销，不能留下半套数据。

### 保存状态可信且可恢复

- [ ] 用统一状态机替换静态绿色 `✅`：`未保存 → 保存中 → 已保存（时间）→ 保存失败 → 正在重试`。
- [ ] `persistBoard` 等异步保存不得 fire-and-forget；错误必须进入 UI，并允许复制诊断信息。
- [ ] 应用关闭/刷新/切账号前 flush 未完成写入，超时则阻止关闭并提供“重试/导出临时副本”。
- [ ] 写入采用事务、版本号或 compare-and-swap，避免并发保存与旧状态覆盖新状态。
- [ ] 崩溃重启时检测未完成 journal/临时快照，提供恢复预览。
- [ ] 加入磁盘满、数据库锁、进程被杀、写入中断和两窗口并发测试。

### 导入与迁移不损伤数据

- [ ] Personal data import 增加 busy 状态、互斥锁、`try/catch`、取消能力，防止重复点击启动两次导入。
- [ ] 不丢弃 `backupPath`、staged 结果与校验详情；在成功页提供“打开备份位置”。
- [ ] 导入前提供预览和冲突策略：新建空间、合并副本、跳过重复；默认不覆盖当前 Board。
- [ ] 导入记录来源、版本、数量和结果；失败时回滚到完整原状态。
- [ ] 明确迁移后的旧数据何时保留、如何恢复、何时可安全清理。

### Electron、网络与密钥安全

- [ ] **[P0]** 增加显式 CSP，生产环境禁止不必要的 `unsafe-inline`、远程脚本和任意连接源。
- [ ] 拦截 `will-navigate`、`setWindowOpenHandler` 与下载；外链仅允许明确协议和可信主机，禁止直接 `shell.openExternal(url)` 打开任意 URL。
- [ ] 审查并启用 `sandbox: true`、`contextIsolation: true`、`nodeIntegration: false`；设置最小化 IPC 暴露面。
- [ ] 默认拒绝摄像头、麦克风、位置、通知等未使用权限；以后按能力逐项授权。
- [ ] 为所有 IPC/HTTP 输入增加 schema 校验、大小限制、超时和统一错误码；Renderer 不得传任意文件路径或命令。
- [ ] OpenAI-compatible Base URL 设为高级选项：URL 校验、仅允许 HTTPS（本机开发例外）、连接测试、明确提示“API Key 会发送到该主机”。
- [ ] 防止重定向把 API Key 带往其他主机；限制 DNS rebinding、私网/metadata 地址和非预期协议。
- [ ] API Key 永不出现在日志、错误、诊断包、前端状态快照或遥测；界面只显示掩码和最后更新时间。
- [ ] 家庭部署启动时检查 `STEPVIEW_SECRET_KEY` 强度、文件权限、默认注册关闭、代理头可信范围和公网暴露风险。
- [ ] 登录限流同时覆盖用户名、IP、设备/会话维度；避免通过错误文案枚举账号。
- [ ] 增加依赖漏洞扫描、secret scanning、CodeQL/SAST 和发布前威胁建模。

## 日志、诊断、隐私与合规

- [ ] 对所有日志字段做数据分级，默认不记录 Board/日记/Prompt/API Key/完整账号/IP。
- [ ] 错误对象序列化前做递归脱敏；第三方 SDK 日志也纳入检查。
- [ ] 日志轮转、大小上限、保留期限、导出和清除均可控。
- [ ] 诊断包生成前显示将包含的文件和字段，用户可取消勾选。
- [ ] 写清简洁隐私说明：哪些数据只在本机、何时会发给模型服务、家庭服务器管理员能看到什么。
- [ ] 如果引入 analytics/crash 服务，先做数据处理清单、供应商评估、地区与删除流程，再接 SDK。
- [ ] 提供“导出我的全部数据”和“删除我的数据”；删除前备份可选，删除后说明哪些系统备份仍会短期保留。
- [ ] 为未成年人或家庭场景审查账号、内容分享和 AI 的额外风险，不用默认公开功能试探边界。
